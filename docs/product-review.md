目标用户：大学生（尤其是博士生）就业信息查询。
评审日期：2026-08-25 · 状态：v1.0 评审

## 已落实（v1.0）

| # | 建议 | 价值 | 实现 |
|---|------|------|------|
| 1 | 首页增加「全国级官方入口」（国家公务员局/国考专题/中国公共招聘网/军队人才网/24365） | 国考与部委直属渠道是博士生高频需求，原设计只有省级下钻，缺少全国级入口 | 首页 NationalSection，5 张直达卡 |

| 4 | 动态 document.title（各路由语义化标题） | 分享链接、浏览器多标签管理的基础体验 | App.tsx TitleWatcher |

## 数据源质量说明

- 省级官方入口：34/34 覆盖，全部经搜索+打开双重核验。
- 地级市公告：按采集波次持续扩充；每个省份的采集缺口由采集 agent 如实记录（不编造 URL 与人数）。
- 附件：能镜像的真实下载并按「年份+省市+文档名称」命名；无法镜像的保留「官网获取」直达。

## v2.0 需求（2026-08-25 二轮评审 · 深色科技版）

背景：目标用户为理工科背景大学生/博士生，全站视觉从「纸质文书风」切换为「深色科技风」；本轮 8 条需求，交互类占一半（1—4）。

### 交互需求

| # | 需求 | 用户价值 | 实现 |
|---|------|----------|------|
| 1 | 全局搜索快捷唤起：任意页面按 `Ctrl+K` 或 `/` 自动回首页并聚焦搜索框，导航搜索按钮展示快捷键徽标 | 信息查询工具的核心路径做到"手不离键盘" | Layout 全局键盘监听 + Home state 聚焦 |
| 2 | 最近访问城市：访问城市页后自动记录（localStorage，最多 6 个），首页 Hero 下方展示「最近访问」快捷 chips，可清空 | 博士生通常紧盯 3—5 个目标城市反复比对，二次访问零成本 | lib/recent.ts + Home RecentCities |
| 3 | 城市页「分享本页」按钮：一键复制当前城市页链接，复制成功即时反馈 | 同学/导师间分享某市统计页是高频协作场景 | CityHeader ShareButton（Clipboard API + 降级） |
| 4 | 返回顶部悬浮按钮（滚动超一屏出现）+ 导航栏底部滚动进度条 | 长页面（城市页/专栏页）导航效率 | Layout BackToTop + ScrollProgress |

### 非交互需求

| # | 需求 | 用户价值 | 实现 |

| 6 | 地图板块深色高对比配色：6 色深色循环、相邻省异色、hover 青色发光描边 | 省份边界清晰可辨，强化"点击下钻"心智 | theme.ts MAP_PROVINCE_COLORS + emphasis 发光 |
