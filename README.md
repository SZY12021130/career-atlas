# 职途图谱 Career Atlas

> 面向大学生（尤其是博士生）的一站式 **公务员 · 选调 · 事业单位 · 人才引进** 官方一手信息图谱，
> 覆盖全国 34 个省级行政区与 1300+ 所本科高校。深色科技风 · 地图下钻 · 纯静态部署。

## 在线访问

**https://szy12021130.github.io/career-atlas/**

无需注册、无需登录，打开即用。建议收藏；站内任意城市页可通过「分享本页」一键复制链接发给同学。

## 功能一览

### 核心查询路径

| 功能 | 说明 |
|------|------|
| 中国地图下钻 | 首页 34 省可点击地图（深色高对比配色，hover 青色发光描边）→ 省级地级市下钻地图 → 城市详情页 |
| 全局模糊搜索 | 城市 / 区县 / 高校名称即输即搜，分组下拉，`↑↓` 选择、`Enter` 跳转、`Esc` 关闭 |

| 三大专栏页 | 选调（定向/普通双轨对比）、事业单位（招聘 vs 录用趋势）、人才引进（政策直达 + 高校人才政策入口） |
| 高校详情页 | 官网 / 人事处招聘 / 人才政策直达，同城公职信息联动，同省高校快速切换 |
| 全国级入口 | 国考、部委直属、军队文职、24365 就业平台 |
| 最新公告速递 | 跨省聚合，按发布日期倒序 |
| 预留标签 | 国企央企 / 互联网大厂 / 博士后（占位，后续开发） |

### 效率交互（v2.0）

| 交互 | 操作 |
|------|------|
| 快捷键唤起搜索 | 任意页面按 `Ctrl+K`（Mac 为 `⌘K`）或 `/`，自动聚焦全站搜索框 |
| 最近访问 | 访问过的城市自动记录（本地存储，最多 6 个），首页搜索框下方一键直达，可清空 |

## 操作指导

1. **按地区查**：首页地图点击省份 → 省级地图点击市 → 城市页查看统计、公告、附件、高校。
2. **按名称查**：`Ctrl+K` → 输入「广州 / 海淀区 / 中山大学」→ 回车直达。
3. **按专题查**：城市页进入「选调专栏 / 事业单位专栏 / 人才引进专栏」查看专项统计与官方入口。
4. **下载附件**：城市页「原始附件」区按年份分组，命名统一为「年份+省市+文档名称」，点击即下；未镜像的附件提供「官网获取」直达。
5. **反复比对目标城市**：最近访问 chips + 分享链接，适合在 3—5 个目标城市间来回切换。

## 数据说明

- 34 省官方入口 100% 覆盖并经人工核验（搜索 + 打开双重验证）。
- 1347 条真实官方公告（2024 年至今），1324 所本科高校，1956 条官方附件镜像记录（1646 个物理文件，约 476 MB）。
- 数据更新至 2026-10-01 前的官方发布（最新公告日期 2026-09-30）。
- 附件按「年份+省市+文档名称」规范命名，可直接站内下载；无法镜像的保留「官网获取」直达。
- 原则：URL、人数、日期只收录官方原文可溯源内容，缺失即留空，绝不编造。发布日期以官方公告页解析结果为准，页头动态系统时间不计入。
- 统计口径、采集方法与免责声明见站内「数据说明」页；产品需求评审记录见 `docs/product-review.md`。

## 技术栈

React 19 · TypeScript · Vite 7 · Tailwind CSS 3.4 · ECharts（地图+统计图表）· Framer Motion / GSAP / Lenis

视觉系统：深色科技风（深蓝黑底 `#0B1220` + 网格辉光底纹 + 青色主色 `#22D3EE` + JetBrains Mono 数字）。

## 本地开发

```bash
npm install
npm run dev      # 本地开发（默认 3000 端口）
npm run build    # 构建（输出 dist/，纯静态）
npm run preview  # 预览生产构建
```

## 部署（GitHub Pages）

站点以 `gh-pages` 分支承载，`base` 为 `/career-atlas/`。更新流程：

```bash
npm run build
# 将 dist/ 内容推送至 gh-pages 分支即可自动更新线上站点
```

路由采用 HashRouter，静态托管下刷新任意子页面不会 404。

## 目录结构

```
public/
  geo/          # 全国+34省 GeoJSON
  data/         # 34省结构化数据 JSON（index.json + {adcode}.json）
  attachments/  # 官方附件镜像（按城市 adcode 分目录）
src/
  components/   # 通用组件（SearchBar/StatCard/EChart/Layout...）
    city/       # 城市详情页各 Section
    columns/    # 选调/事业单位/人才引进专栏
    university/ # 高校详情页组件
  lib/          # data/theme/search/recent 等核心逻辑
  pages/        # Home / Province / City / University / About / Reserved
docs/           # 数据 Schema、产品评审等文档
```
